# Fonts

OFL-licensed only. The Neutral pack expects:

- `Inter-Black.ttf` (https://fonts.google.com/specimen/Inter)
- `InstrumentSerif-Regular.ttf` and `InstrumentSerif-Italic.ttf` (https://fonts.google.com/specimen/Instrument+Serif)

Download the families, copy the three files here. `uv run engine/packs/load.py Neutral caption` confirms they resolve.
